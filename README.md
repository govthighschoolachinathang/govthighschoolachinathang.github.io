# Govt. High School Achinathang

One-page website for Government High School Achinathang, Khaltse, Leh, UT of Ladakh (CBSE Affiliation No. 3720134), served with GitHub Pages.

- `index.html`: the page (styles are inline)
- `images/school.jpg`: school photo
- `documents/`: mandatory public disclosure PDFs, linked from the Documents section

To update a document, replace the PDF in `documents/` with the same filename, or add a new file and a matching line in the Documents list in `index.html`.
